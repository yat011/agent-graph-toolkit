# Research: Primary Sources and Citation

Adapted from the `mattpocock-skills` plugin's `research` skill — this project's researcher reports
inline to whoever dispatched it rather than persisting findings to its own file, so only the
source-quality and citation rules carry over.

## Primary sources only

Investigate against primary sources — official docs, source code, specs, first-party APIs — not a
secondary write-up of them. Follow every claim back to the source that owns it, not a blog post or
memory of how it "usually" works, especially for anything version-specific.

## Cite every claim

Every claim needs a citation at the point it's made, not gathered into a bibliography at the end:
`file:line` for codebase claims, a URL for web claims. A claim with no citation isn't a finding
yet.
